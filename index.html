❓ How to use ShipLog

For the 2 developers (daily)

  1. Morning: click ＋ Add New Task — the form has only 3 fields: Goal, Tasks (one per line), Expected Deliverable. Only your section of the Daily Goal document is created/updated.
  2. As you finish something: take a screenshot + copy the live/staging link and GitHub PR link.
  3. Before you close your laptop: click Log Today's Work (2 min). If something is delaying you, write it in the Blocker field so it can be followed up.
  4. Share it: let anyone open this page and scroll it, or print/PDF the Daily Goal document.

For the boss (2 minutes)

  1. Check the % complete and overdue cards near the top of the Dashboard section.
  2. Scroll to Recently built — click screenshots and live links. That is the actual work, not a claim.
  3. Check Needs attention: anyone who hasn't logged today, overdue tasks, blockers waiting on you.
